## ADDED Requirements

### Requirement: 上传文件分片接口
系统必须提供POST /api/file/chunk接口用于接收文件分片，请求参数使用表单类型。

#### Scenario: 成功上传文件分片
- **WHEN** 前端通过表单方式发送文件分片，包含文件流、文件名、分片索引、总分片数
- **THEN** 系统接收分片并在temp目录下创建该文件的临时文件夹，将分片保存其中，返回成功响应

#### Scenario: 分片参数验证失败
- **WHEN** 前端发送的分片缺少必要字段（文件流、文件名、分片索引、总分片数）
- **THEN** 系统返回400错误，提示缺少必要参数

### Requirement: 文件分片类封装
系统必须使用类来封装文件分片，包含文件流、文件名、分片索引、总分片数这些属性。

#### Scenario: 创建分片对象
- **WHEN** 接收到文件分片数据
- **THEN** 系统创建包含文件流、文件名、分片索引、总分片数属性的分片对象

### Requirement: 合并文件接口
系统必须提供POST /api/file/merge接口用于合并文件分片。

#### Scenario: 成功合并文件
- **WHEN** 前端发送合并请求，包含fileName和totalChunks参数，所有分片已接收完毕
- **THEN** 系统校验分片完整性，按分片索引排序，使用文件流合并文件，返回响应：
  - code: 200
  - message: "文件合并成功"
  - data.fileUrl: "/uploads/文件名"
  - data.fileSize: 文件大小（字节）

#### Scenario: 分片不完整
- **WHEN** 合并时发现分片数量不等于totalChunks
- **THEN** 系统返回错误响应，提示分片不完整

#### Scenario: 文件不存在
- **WHEN** 合并请求中的fileName对应的临时文件夹不存在
- **THEN** 系统返回错误响应，提示文件未找到

### Requirement: 分片排序与流式合并
系统必须读取临时文件夹，按分片索引排序，利用文件流创建目标文件的可写流，依次将文件分片通过管道写入目标文件。

#### Scenario: 按索引排序分片
- **WHEN** 读取临时文件夹中的分片文件
- **THEN** 系统按分片索引从小到大排序

#### Scenario: 流式写入目标文件
- **WHEN** 分片已排序
- **THEN** 系统创建目标文件的可写流，通过管道将分片依次写入，目标文件保存在项目的files目录下

### Requirement: 临时文件清理
系统必须在文件合并完成后删除temp目录下的临时文件。

#### Scenario: 合并成功后清理临时文件
- **WHEN** 文件合并成功完成
- **THEN** 系统删除temp目录下该文件的临时文件夹及其所有分片文件
